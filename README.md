# Portfolio: Nuxt 3 · Tailwind · GSAP

Static, frontend-only. Edit your details in `composables/usePortfolio.js`.

```bash
npm install
npm run dev        # http://localhost:3000
npm run generate   # static site in .output/public
```

- `composables/useAnimations.js`: every scroll behaviour (GSAP)
- `assets/css/main.css`: light/dark colour tokens
